# Code Lantern Project Instructions

- Project: **Code Lantern CLI** (`codelantern-agent-cli`, terminal command `lantern`)
- AI Model: **Google Gemini API** (`gemini-3.8-flash`)
- Cross-platform support: macOS (Apple Silicon and Intel) and Windows (Command Prompt, PowerShell)
- Coding standards: Clean TypeScript, ES Modules, Node.js 18+ APIs
- Testing: Run `npm test` to verify security sandboxes, path resolution, tool execution, session storage, and line ending compatibility
